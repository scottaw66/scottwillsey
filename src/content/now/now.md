## Current Personal Status
>
> I started getting tired of watching NPM get owned every week, and I decided I don't want websites that rely on NPM and JavaScript as the framework. And since Astro does, I decided to convert everything to Zola, which is a Rust framework, and I could also do the build with very little third-party software involved.

## Current Projects

- Migrating all my sites from Astro (npm/javascript supply chain that's currently just a massive security risk, begging to be p0wned) to Zola. Fable 5 did this site in about an hour... not a bad bit of work considering how much custom stuff I had going on with this site.
